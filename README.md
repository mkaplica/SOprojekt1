# SOprojekt1
Projekt nr 1 z przedmiotu **Systemy Operacyjne**, ITE SEM 5.
Projekt dotyczył wielowątkowej implementacji algorytmu Dijkstry dla znalezienia najkrótszej ścieżki w grafie.

### Autorzy
Michał Kapica, Krzysztof Wiłnicki, Mateusz Wasilewki
